# EasyVPN для Windows

Здесь лежат готовые установщики приложения [EasyVPN](https://easyvpn.shop). Обычно проще скачать его со страницы [easyvpn.shop/download](https://easyvpn.shop/download).

Windows может показать предупреждение: нажмите «Подробнее», затем «Выполнить в любом случае».

## Что в каждом выпуске

- `EasyVPN-Setup-x.y.z.exe`: установщик.
- `latest.json`: сведения для автообновления. Каждое обновление подписано, и приложение проверяет подпись перед установкой.
- `sing-box-*-source.tar.gz`: исходный код ядра [sing-box](https://github.com/SagerNet/sing-box), которое входит в приложение без изменений. Лицензия GPL-3.0-or-later.

Поддержка: [@eassyvpn_bot](https://t.me/eassyvpn_bot), support@easyvpn.shop.
